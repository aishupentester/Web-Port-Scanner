# Web-Based TCP Port Scanner

A web-based TCP port scanner developed using Python Flask and socket programming.

## Features

* Scan common TCP ports
* Detect open ports
* Simple HTML/CSS user interface
* Flask backend

## Technologies Used

* Python
* Flask
* HTML
* CSS
* Socket Programming
